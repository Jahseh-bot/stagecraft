# 阶段包由现有 AI 编程工具执行

用户确认采用推荐方案：包提供 Skills、模板和确定性脚本，由现有 AI 编程工具执行阶段工作。第一版不自建模型运行器；这让开发重点集中在独立阶段交付，代价是宿主发现、工具权限和执行行为需要分别验证。

阶段包在发布产物中自包含，不运行时依赖其他阶段包。安装工具源码可在仓库内复用，构建时复制到各包，以避免修改共用运行时迫使用户协调升级所有包。

修订原因：原方案把用户的自动交付构想缩减为手工调用 Skills。用户后续澄清需要任意阶段切入、必要澄清后自动推进，并支持人工介入。此前“无需运行器”的结论不再适用。
