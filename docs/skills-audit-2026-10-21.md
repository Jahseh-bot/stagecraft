# Skills 扫描与优化报告（2026-10-21）

## 范围与方法

扫描 packages 下的源和运行时副本、根 skills 分发目录共 414 个 SKILL.md 入口；包括 40 个独立三方方法和 8 个独立自研技能（七阶段及测试用例设计，源/公开目录共16份自研入口）。副本不作为新增技能计数。排除 node_modules、output 等外部依赖与临时产物。

全量进行入口元数据、相对引用、源出处及哈希扫描；自研内容逐阶段核对职责、输入、选择/评审、执行闭环、覆盖、异常恢复、输出与交接。三方做结构/来源/内容完整性与覆盖目录审查，不改变其原文，也未宣称逐一运行所有技术示例。

机器报告：运行 `npm run build && npm run audit:skills`，读取 `output/audits/skills.json`。三方源基线在 `tooling/upstream-integrity.json`。本次修改前后额外核对 5,004 个现有三方源及分发文件，未发现改变或缺失；新增自研资源不计入三方统计。

## 主要发现与处理

| 发现 | 处理 | 位置 |
| --- | --- | --- |
| 阶段入口只有概括步骤，执行深度依赖agent经验 | 七阶段新增详细环节、输入/输出、检查及评审指南 | 各阶段 references/stage-guide.md |
| 跨产品形态与风险容易遗漏 | 增加适用性矩阵，覆盖角色/数据/状态、多端、API/CLI、数据任务、AI、可靠性与运维 | tooling/skill-shared/coverage.md |
| 方案确认后缺少成果版本评审约束 | 成果展示/用户评审门禁、内容快照、变更与下游失效，助手升级v2 | artifact-reviews.md、handoff.mjs |
| 测试容易直接跑命令而缺少可追溯用例 | 保留并扩展先设计/补漏/评审用例再执行，增加复杂任务与用例维护 | test-case-design/ |
| 三方工具/宿主和引用有差异 | 自研只读适配说明；不改原文 | upstream-adapters.md |
| 缺少持续防止三方被误改的检查 | 全量入口扫描、固定源树哈希和自动测试 | tooling/audit-skills.mjs、tests/skills-audit.test.mjs |

## 各阶段覆盖扩展

- discover：用户/购买者、场景证据、反证、替代方式、商业与分发假设、MVP与实验。
- spec：PRD结构、角色权限、状态与条件规则、数据生命周期、质量约束、可验证AC、变更追踪。
- design：信息结构、低保真流程、视觉比较、页面/组件状态、多端可访问性、实际预览与资源交接。
- architect：系统/模块/数据/API契约、并发/可靠性、安全/成本、技术探针、迁移与实施验证计划。
- build：切片实现、真实集成、类型专项检查、失败诊断、代码差异检查、可运行展示与交接。
- test：评审后的用例、验证分层、环境数据、专项适用性、缺陷与回归、覆盖分母与发布建议。
- deploy：制品/配置/迁移、策略与回滚、发布前后评审、新版本核实、运行手册与后续维护。
- test-case-design：多角色、数据迁移、时间/金额、AI、多端，以及既有用例ID和历史结果维护。

每个维度记录适用/不适用/未知依据；不借全面性扩大用户未选择的产品功能。各阶段依然先给推荐在前的选项和自由输入，成果存到项目并经具体版本评审。

## 保留的三方限制

`python-design-patterns` 的 Related Skills 指向未随包提供的 `../python-project-structure/SKILL.md`。这是现存延伸引用，扫描会在各副本中报告；本次不更改或删除它，也不伪造依赖已经存在。自研适配指引说明如何使用本项目架构指引及现有仓库约定，确需专项方法时另行核验新增。

三方技术示例仍需在目标项目的版本、工具和授权环境中验证；结构扫描与哈希完整性不等于跨宿主效果认证。没有新增三方方法，保留现有40个方法及许可证。

## 验证结果与限制

- `npm test`：74项通过，包含九项交接状态/评审/版本回归检查及三方完整性检查。
- 官网生产构建成功，4项内容、页面与链接检查通过。
- `npm run audit:skills`：414个入口，自研引用与三方固定源检查无错误；三方延伸引用作为已知警告保留。
- 原有通用 skill-creator 快速校验器不接受七个阶段入口现有的 `compatibility` 元数据字段，因此不能把该工具结果称为全体格式通过。保留现有字段，由仓库的安装、入口与引用契约检查验证；测试用例子技能此前通过该快速校验。未为迁就校验器改动三方内容。
- 没有新增真实项目/多宿主行为对照实验。运行用例、用户评审与验证证据仍是后续质量判断依据。
