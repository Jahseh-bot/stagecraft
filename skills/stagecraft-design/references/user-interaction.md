# 宿主原生用户交互

适用于七阶段的澄清、方案选择、修改意见、产物/用例评审和发布决策。优先调用当前 harness 的真实选择/问答工具，不用聊天里的“回复1/2”冒充选项卡。已有明确决定直接复用，不为演示卡片制造问题。宿主系统规则、当前模式和工具用途限制优先。

## 能力发现与适配

读取当前可用工具的名称、说明和输入schema；有延迟工具发现能力时仅查询相关问答工具。安装目录或宿主名称不是工具可用的证据，不调用不存在的工具，也不为了使用卡片擅自切模式、安装MCP或改全局设置。

|宿主|发现线索，不是固定调用协议|适配要求|
|---|---|---|
|Codex|request_user_input；某些桌面会话有 request_user_input_async|按当前schema确认模式/用途。同步工具可能仅Plan模式可用；异步工具返回已创建不等于用户回答。不能用不允许审批的工具收集发布授权|
|Claude Code|AskUserQuestion|使用当前schema的选项/描述和自由输入能力；自动继续/自动选择不能替代用户确认|
|Gemini CLI|ask_user|按当前schema构造问题类型与选项；headless或交互不可用时保留待答状态|
|OpenCode|question|按当前工具的header/选项/描述/自定义输入能力映射；不假设所有版本参数相同|
|GitHub Copilot|CLI可发现ask_user；IDE/云端工具不同|以实际工具清单为准，不把CLI名称硬套到全部宿主|
|Cursor及其他harness|发现当前提供的AskQuestion或等价选择/问答工具（若存在）|不假定名字、数量限制或自由输入字段；没有工具时明确降级|
|通用/无交互运行|可用的原生问答或宿主提供的elicitation能力|只有确实暴露且允许当前用途才调用；无工具保留pending/blocked|

适配顺序：原生选项工具 → 宿主已提供且支持选择的问答/elicitation工具 → 原生自由输入工具（无法渲染选项时说明）→ 编号聊天兜底。不要用终端read、GUI自动点击、自建网页、answers.json或启动嵌套agent来模拟选择。工具不支持自由输入但仍支持卡片时，保留卡片并提供“自定义”路线；选择后用可用自由输入工具或聊天收集正文，不必因此把全部交互降为文字。

## 题目和选项

- 每次聚焦一个决策，通常2–3个有意义选项；第一项明确标“推荐”，简述原因和取舍。复杂方案先给可打开的对比/预览，卡片引用方案ID和版本，不能只有含义不明的“方案一”。
- 问题本身包含足够上下文、需决定事项、适用范围和未决影响；不能依赖工具面板可能隐藏的上一段聊天。
- 原生已有Other/自由输入入口时不重复添加“其他”；无此能力时在schema允许范围内增加“自定义”，选中后先收集补充，不当作通过。
- 单选用于互斥方案；仅在工具支持且选项独立时多选，不能把互斥架构混成默认组合。遵守宿主数量/长度限制，有依赖的问题逐步询问。
- 产物评审必须指向具体版本和链接，可选“通过此版本”“需要修改”，推荐取决于实际质量；通过方案不等于通过未来产物。发布选择须包含实际目标、版本和影响，并满足工具用途与宿主审批要求。

## 停顿与真实回答

1. 先保存决定草案或成果；产物必须先submit为awaiting_review，并展示可打开的内容，再请求用户评审。提交后允许的例外仅是展示/打开该成果和发起该版本的原生评审，不做新实现或加载下阶段技能。
2. 发起异步卡片后结束当前轮，保持待答。不能轮询、重复开卡、把工具返回的accepted或默认预选当作回答。后续真实用户回复才解析执行。
3. 同步阻塞工具若返回用户真实答案，可以记录该答案及精确版本，但本轮交付仍到此结束；不得在同一交付轮继续下一阶段。普通方案选择获得真实答复后可在该选择范围内工作，最终成果仍单独评审。
4. 取消、关闭、跳过、空答案、超时、headless自动回答均为未确认。若来源无法证明是用户实际输入，保持pending，不写approved、不complete；不能“按推荐继续”。
5. 自定义文字优先保留原文，不能静默吸附到最接近的选项。有歧义只澄清关键差异。用户明确的“通过v1.1”等聊天回复仍有效，不强迫重新点卡片。
6. 答复关联decision ID与所展示revision/submission。旧卡片针对旧版本的通过不能放行新版本；需要修改则留在当前阶段，修订后重新展示并发起新评审。

记录：decision ID、阶段/类型、目标版本、选项、推荐理由、实际工具、发送状态、用户回复原文/选项ID及来源、结果；降级时写具体原因。避免将整个工具原始响应中的敏感信息写入项目。交接助手仍只校验记录，不自动证明工具答案来自真人。

## 降级必须可见

工具未暴露、模式不允许、用途不支持或实际调用失败时，一次说明具体原因和替代方式。先处理可恢复schema错误；没有新依据不反复重试。保留同一决策和选项，在聊天中提供编号及自由补充，等待真实答复。不能声称已弹出卡片，更不能在终端让用户执行自然语言。
