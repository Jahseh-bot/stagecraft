# 温度换算小工具

为普通用户提供可在本机运行的网页，把摄氏温度转换为华氏温度。

## 必需功能

- 页面提供摄氏输入框、换算按钮和结果；支持负数与小数。
- 换算公式 F = C × 9 / 5 + 32。
- 空输入和非数字不能当作 0，应显示错误。
- 提供 GET /api/convert?c=<number>，返回 JSON {"fahrenheit": number}；无效输入返回 HTTP 400。
- GET /health 返回 HTTP 200，内容包含 "ok"。
- 本地 HTTP 服务监听 127.0.0.1:43187。
