# 固定版本与升级

## 升级时注意什么

第一次请固定使用本文的 `0.3.0`。恢复旧任务时继续使用创建它时的版本，不要中途改成 `@latest`。已有项目和 `.stagecraft` 目录一起保留；开始新项目时再选择新版本，并阅读对应版本说明。

本指南讲的是使用公开 npm 包，不需要执行源码仓库里的 `npm run build` 或 `npm run release`。维护和发布软件的流程另见 [维护者发布指南](https://github.com/Jahseh-bot/stagecraft/blob/main/docs/npm-publishing.md)。
