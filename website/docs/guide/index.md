# 什么是 Stagecraft

Stagecraft 将各阶段成熟方法筛选并组合成七个产品工作入口：创意、需求、设计、架构、开发、测试、部署。你不必研究底层 Skills 的选择与搭配，专心说明产品目标、选择关键方案和检查成果。

每个技能都会检查输入、完成本职工作、实际验证、在授权范围内修复，再留下可继续使用的交接记录。你不需要操作 runner，也不需要手写答案 JSON。

## 先了解你将完成什么

第一次可以做一个温度换算网页。安装 build 和 test 技能后，在你正在使用的 agent 中描述需求，要求它实现并测试。关键方向先给方案与推荐理由，由你选择确认；已确认范围内的技术细节、验证和修复由 agent 自动处理。

0.4.1 是已发布到 npm 的 Skills-first 版本，下面使用 npm 自带的 npx 直接安装技能，无需下载 Stagecraft 源码。0.3.0 为旧版 runner；0.3.1 曾部分发布，仅 architect 已上传，不要将它作为完整新版安装。

安装技能不会自动调用模型，也不会替你购买或配置模型账号。执行时使用当前 coding agent 的账号、额度、工具和权限。
